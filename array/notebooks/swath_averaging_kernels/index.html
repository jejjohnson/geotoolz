    Swaths — an EMIT granule and TROPOMI averaging kernels on GeoSwath¶

    Imaging spectrometers and trace-gas sounders deliver their data in sensor geometry: rows along track, columns across, each pixel with its own latitude and longitude. Orthorectifying first would resample the very radiances a retrieval needs. geoarray.GeoSwath carries them as they are: the data with named dims, and lat/lon as pytree leaves, so a new granule of the same shape reuses a compiled program.

    The data here are synthetic, shaped like the real products, so the notebook runs offline.

    What you'll learn:

    1. Build an EMIT-like swath with a SpectralAxis of 285 bands and select bands by name.
    2. Reduce over the swath with pipekit-array's dim-level functions, and see why a per-column statistic is a DimArray, not a swath.
    3. Apply TROPOMI-style averaging kernels on a GeoSwathProfile with one KernelOp, eagerly and under jit.
    4. Cross to xarray with 2-D lat/lon coordinates and back.

    1. An EMIT-like granule¶

    EMIT measures 285 bands from 381 nm to 2493 nm. A small granule of 64 × 48 pixels, on a track tilted across the Permian Basin: the latitude and longitude of every pixel are leaves of the carrier.

    In [3]:

    rows, cols = 64, 48
# along-track and across-track unit steps, in degrees, for a tilted orbit
i, j = np.meshgrid(np.arange(rows), np.arange(cols), indexing="ij")
lat = 31.8 - 0.0006 * i + 0.0002 * j  # (row, col) float64
lon = -103.9 + 0.0002 * i + 0.0006 * j  # (row, col) float64

wavelength = np.linspace(381.0, 2493.0, 285)  # (band,) nm
bands = SpectralAxis(
    names=tuple(f"b{k:03d}" for k in range(285)),
    wavelength_nm=wavelength,
    fwhm_nm=np.full(285, 8.5),
)

# a smooth radiance spectrum with a methane absorption dip near 2300 nm,
# deeper inside a synthetic plume
plume = np.exp(-(((i - 30) / 8.0) ** 2 + ((j - 20) / 5.0) ** 2))  # (row, col)
spectrum = 0.3 + 0.7 * np.exp(-(((wavelength - 900.0) / 700.0) ** 2))  # (band,)
dip = np.exp(-(((wavelength - 2300.0) / 30.0) ** 2))  # (band,)
radiance = (
    spectrum[:, None, None] * (1.0 - 0.3 * dip[:, None, None] * plume)
    + rng.normal(0.0, 0.002, (285, rows, cols))
).astype(np.float32)  # (band, row, col) float32

emit: GeoSwath = GeoSwath(
    radiance,
    lat,
    lon,
    dims=("band", "row", "col"),
    coords=(bands,),
    fill_value=np.nan,
)

    2. Reductions: what stays a swath¶

    The adapter keeps the geolocation while it still describes the result. A mean over band is a swath; a mean over row (one value per column, a classic destriping statistic) has no geolocation left, so it is a plain DimArray with the band labels.

    3. TROPOMI averaging kernels¶

    A trace-gas retrieval reports, per pixel, an averaging kernel A on its retrieval layers and the prior profile x_a. To compare a model profile x with the retrieved column, apply the kernel:

    $$\hat{c} = c_a + \sum_k h_k \, A_k \, (x_k - x_{a,k})$$

    where $h_k$ is the pressure weight of layer $k$ ($\sum_k h_k = 1$), so $\hat{c}$ is a column-averaged mixing ratio. This example gives the 12 layers equal pressure thickness, $h_k = 1/12$; a real retrieval reads $h$ from the product.

    TROPOMI's CH₄ product has 12 layers in pressure. The kernels and priors are GeoSwathProfiles: swaths with a level dim and a VerticalAxis.

    In [6]:
    Copied! 
    pressure = Vertical(kind="pressure", units="hPa", positive="down")
layers = VerticalAxis(values=np.linspace(1000.0, 100.0, 12), vertical=pressure)
nr, nc = 40, 30
ti, tj = np.meshgrid(np.arange(nr), np.arange(nc), indexing="ij")
t_lat = 31.5 + 0.06 * ti  # (row, col)
t_lon = -104.5 + 0.07 * tj  # (row, col)

# kernels peaking in the lower troposphere, varying with the scene
height = np.linspace(0.0, 1.0, 12)  # (level,)
ak = np.exp(-((height[:, None, None] - 0.2) ** 2) / 0.1) * (
    0.9 + 0.1 * rng.random((1, nr, nc))
)  # (level, row, col)
prior = np.full((12, nr, nc), 1850.0)  # (level, row, col) ppb
truth = prior + 60.0 * np.exp(-(((ti - 20) / 6.0) ** 2 + ((tj - 15) / 6.0) ** 2))[None]

kernels: GeoSwath = GeoSwath(
    ak, t_lat, t_lon, dims=("level", "row", "col"), coords=(layers,)
)
priors = kernels.with_data(prior)
model = kernels.with_data(truth)
assert matches(kernels, GeoSwathProfile)

    One L1 kernel, written on plain arrays with the layer axis last, wrapped once as a KernelOp. The carriers must share their geolocation exactly; the dispatch checks it and never aligns.

    In [7]:
    Copied! 
    def apply_kernel(
    a: np.ndarray, x: np.ndarray, xa: np.ndarray, *, c_a: float
) -> np.ndarray:
    # ĉ = c_a + Σ_k h_k A_k (x_k − x_a,k), over the last (layer) axis,
    # with equal pressure weights h_k = 1/K
    h = 1.0 / a.shape[-1]
    return c_a + (h * a * (x - xa)).sum(-1)


smoothed = KernelOp(
    apply_kernel,
    "(l),(l),(l)->()",
    core={"l": "level"},
    c_a=1850.0,
)
column = smoothed(kernels, model, priors)  # (row, col): a GeoSwath
print(type(column).__name__, column.dims)

    The same KernelOp runs on JAX carriers under jit. A second granule with the same shape and new lat/lon reuses the compiled program: the geolocation is a leaf, not part of the cache key.

    Copied! 
    traces = 0


def run(a: GeoSwath, x: GeoSwath, xa: GeoSwath) -> GeoSwath:
    global traces
    traces += 1
    return smoothed(a, x, xa)


fast = jax.jit(run)
on_jax = [c.to_jax() for c in (kernels, model, priors)]
first = fast(*on_jax)
moved = [

    Recap¶

    • A swath stays in sensor geometry: data with named dims, lat/lon as leaves, coordinates (SpectralAxis, VerticalAxis) as static labels.
    • pipekit-array's functions and KernelOps run on it; a result that consumed row or col is a DimArray.
    • Under jit, new geolocation of the same shape costs no recompile.
