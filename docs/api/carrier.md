# Carrier helpers and contract checks

The helpers every geotoolz operator uses to keep the `GeoTensor` carrier
contract, public so an operator written on top of the stack keeps it the same
way, and `check_operator`, which runs the package's own contract checks on any
operator. The rules are in [Concepts](../concepts.md) and
[Define an operator](../recipes/define-an-operator.md).
