Coupling classes: which dims an operator mixes
An operator couples a dim when one output depends on two or more inputs that differ along it. Each row down adds one coupled dim; the counts cover the 275 public geoops operators.
volumetricspacelevel4
Gradient3D · Laplacian3D · Divergence3D · Curl3D
a stencil across (level, y, x); reach as for spatial
pointwisenone99
DNToReflectance · ApplyMask · LogScale · Rasterize (reads only the grid) · MinMaxScaler (fitted over space, time)
Split anything: patches, bands and frames give the same answer, unless a state is fitted over them
spectralband35
NDVI (band reduce) · BandMath · ContinuumRemoval · MatchedFilter (fitted over space, time)
Keep a pixel's bands together; tile and split time freely
spatialspace94
Gradient2D (reach 1) · DilateMask (reach = iterations) · GaussianDenoise (⌈4σ⌉) · Reproject (regrid, global) · LabelConnectedComponents (global)
Tiles overlap ≥ 2 × reach, or the seams differ; a global reach means patching changes the answer (ApplyToChips warns)
temporaltime4

Keep the whole time stack; tile and pick bands freely

effect, per dimwhat happens to a dim it doesn't couple, or how it couples: keep · select · reduce · mix · expand · split · join · regrid
reachpixels of context each output reads: an int, or global; reach_of(op) follows the arguments (spatial_reach())
fitted overdims a learned state is estimated over though the apply is local: a scaler is pointwise but fit sees every pixel
