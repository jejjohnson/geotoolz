    API Reference — Composition Core¶

    The Operator / Sequential / Graph composition algebra lives in the carrier-agnostic pipekit framework and is re-exported at geotoolz.* (and pipekit.*) for convenience. The only geotoolz-specific addition on this page is ModelOp, which lives at geoops.learn.

    For the model behind these primitives, read the Concepts page first.

    Base¶

    pipekit.Operator ¶

    Bases: ConfigMixin

    Base class for pipekit operators.

    Subclasses implement _apply(self, *args, **kwargs). The base class dispatches __call__ to either _apply (eager) or Node construction (symbolic) based on whether any positional argument is a graph node.

    Attributes:

    Name Type Description
    forbid_in_yaml bool

    True on subclasses that directly hold non-serialisable user state (callables, closures, runtime arrays, RNGs). YAML loaders and from_state refuse to instantiate flagged operators; parallel.check_pickleable surfaces them as pickleability warnings. Operators that only nest other operators leave this False — the walker finds flagged children structurally. Default False.
    _terminal bool

    True on subclasses that legitimately return None (or otherwise break the carrier-in / carrier-out contract). Sequential rejects terminal operators except as the last step. Default False.
    backends tuple[str, ...] | None

    The array backends the operator runs on ("numpy", "jax", "dask"), or None (the default) for an operator that does not care. When set, an eager call whose carriers or arrays sit on another backend, or on several, raises pipekit.adapters.BackendError before _apply runs: inputs never move between backends silently. Values with no backend (numbers, strings, tables) are not checked.
    Example

    Define and compose::

    class Scale(Operator):
    def __init__(self, factor: float) -> None:
        self.factor = factor

    def _apply(self, x):
        return x * self.factor

pipe = Scale(0.5) | Scale(2.0)   # Sequential([Scale(0.5), Scale(2.0)])
assert pipe(10.0) == 10.0

    class Operator(ConfigMixin):
    """Base class for pipekit operators.

    Subclasses implement ``_apply(self, *args, **kwargs)``. The base
    class dispatches ``__call__`` to either ``_apply`` (eager) or
    `Node` construction (symbolic) based on whether any positional
    argument is a graph node.

    Attributes:
        forbid_in_yaml: ``True`` on subclasses that *directly* hold
            non-serialisable user state (callables, closures, runtime
            arrays, RNGs). YAML loaders and `from_state` refuse to
            instantiate flagged operators; `parallel.check_pickleable`
            surfaces them as pickleability warnings. Operators that only
            nest other operators leave this ``False`` — the walker finds
            flagged children structurally. Default ``False``.
        _terminal: ``True`` on subclasses that legitimately return
            ``None`` (or otherwise break the carrier-in / carrier-out
            contract). `Sequential` rejects terminal operators except
            as the last step. Default ``False``.
        backends: The array backends the operator runs on (``"numpy"``,
            ``"jax"``, ``"dask"``), or ``None`` (the default) for an
            operator that does not care. When set, an eager call whose
            carriers or arrays sit on another backend, or on several,
            raises `pipekit.adapters.BackendError` before ``_apply``
            runs: inputs never move between backends silently. Values
            with no backend (numbers, strings, tables) are not checked.

    Example:
        Define and compose::

            class Scale(Operator):
                def __init__(self, factor: float) -> None:
                    self.factor = factor

                def _apply(self, x):
                    return x * self.factor

            pipe = Scale(0.5) | Scale(2.0)   # Sequential([Scale(0.5), Scale(2.0)])
            assert pipe(10.0) == 10.0
    """

    forbid_in_yaml: ClassVar[bool] = False
    _terminal: ClassVar[bool] = False
    backends: ClassVar[tuple[str, ...] | None] = None
    # Stateful-pipeline marker — `StatefulOperator` overrides to True; the
    # `Sequential` plumbing reads this to decide whether to thread state.
    # See `pipekit.state` (Group M).
    _is_stateful: ClassVar[bool] = False

    def __call__(self, *args: Any, **kwargs: Any) -> Any:
        """Dispatch eager vs symbolic on positional arguments.

        If any positional argument is a `Node` (which `Input` subclasses),
        all positional args must be `Node`s and the call returns a new
        `Node` recording this operator and its parents. Otherwise the
        call routes to `_apply`. Subclasses override `_apply`, not
        `__call__`.

        Raises:
            BackendError: ``backends`` is set and an input sits on another
                backend, or the inputs sit on several.
            TypeError: if graph-construction mode is triggered (at
                least one `Node` arg) but other positional args are not
                `Node`s. Mixing nodes and literals would crash
                downstream when `Graph` walks ``parents``; reject it at
                construction with a clear message.
        """
        # Lazy import to break the operator <-> graph circular dependency.
        from pipekit._base.graph import Node

        if any(isinstance(a, Node) for a in args):
            non_node = [
                (i, type(a).__name__)
                for i, a in enumerate(args)
                if not isinstance(a, Node)
            ]
            if non_node:
                raise TypeError(
                    f"{type(self).__name__}: graph-construction mode requires "
                    "every positional arg to be a Node. Non-Node arg(s) at "
                    f"position(s) {non_node!r}. Wrap literals in `Const(value)` "
                    "or supply them as a separate `Input`."
                )
            return Node(operator=self, parents=tuple(args))
        self._check_backends(args, kwargs)
        out = self._apply(*args, **kwargs)
        # Reserved hook dispatch — no-op in v0.1; Spy/Hook family lands later
        # without requiring every Operator subclass to be edited.
        self._dispatch_post_apply_hooks(args, out)
        return out

    def _check_backends(self, args: tuple[Any, ...], kwargs: dict[str, Any]) -> None:
        """Raise `BackendError` when the inputs break ``backends`` (if set).

        `__call__` runs it before ``_apply``; anything else that calls
        ``_apply`` directly (`AsyncMap` awaiting a coroutine ``_apply``)
        runs it too.
        """
        if self.backends is not None:
            _require_backends(type(self).__name__, self.backends, args, kwargs)

    def _apply(self, *args: Any, **kwargs: Any) -> Any:
        """Implement the operator's behaviour. Override in subclasses."""
        raise NotImplementedError(f"{type(self).__name__} must implement _apply().")

    def _dispatch_post_apply_hooks(self, args: tuple[Any, ...], out: Any) -> None:
        """No-op in v0.1. Reserved for the Spy/Hook family (Group E v0.2)."""
        return None

    def compute_output_signature(self, input_signature: Any) -> Any:
        """Return the signature of this operator's output given an input signature.

        Default is passthrough — most carrier-agnostic operators preserve
        shape and dtype. Subclasses that reshape / reduce / retype override.
        Returning ``None`` signals "this operator does not track shape"
        (carriers without named dimensions); `Sequential.summary` and
        `Graph.summary` show ``?`` for it, and every later step in a
        `Sequential` is unknown too.

        Handed a carrier instead of a signature, the default reads the
        carrier's `Signature` through its registered adapter
        (`pipekit.adapters.signature_of`), so ``Sequential.summary`` can
        start from data.

        The annotation is `Any` rather than `Signature | None` so domain
        libraries can thread their own signature types.
        """
        return signature_of(input_signature)

    @property
    def state(self) -> dict[str, Any]:
        """Return a JSON-serialisable state record for this operator."""
        return {
            "module": type(self).__module__,
            "class": type(self).__name__,
            "config": self.get_config(),
        }

    @classmethod
    def from_state(cls, state: dict[str, Any]) -> Operator:
        """Reconstruct an operator, and any operators nested in it, from `state`.

        Resolves classes among `cls` and all its transitive subclasses,
        so ``Operator.from_state(state)`` resolves any imported subclass;
        nothing is imported. Config values are rebuilt recursively: a
        nested `state` record becomes an operator, an
        ``{"exception": "module.Name"}`` record becomes that (already
        imported) exception class, lists and dicts are rebuilt item by
        item, and JSON primitives pass through. The class's
        `from_config` then builds the operator.

        Raises:
            ValueError: if a state record is malformed.
            TypeError: if a class isn't a loaded `Operator` subclass, or an
                exception record doesn't name a loaded exception class.
            RuntimeError: if any class in the tree is marked
                ``forbid_in_yaml``, or a config holds a value that is not
                JSON (or a nested payload without a ``module``, as
                written before nested round-trips existed).
        """
        module_name, class_name, _ = _check_record(state)
        op_type = resolve_loaded(module_name, class_name)
        if not issubclass(op_type, cls):
            raise TypeError(f"{module_name}.{class_name} is not a {cls.__name__}.")
        return build_operator(state, resolve_loaded)

    @classmethod
    def from_config(cls, config: dict[str, Any]) -> Self:
        """Build an operator from its decoded `get_config()` record.

        The default calls ``cls(**config)``, which is right for every
        operator whose config keys are its constructor's arguments.
        Operators whose config is not a constructor call (`Graph`,
        whose config is a topology) override this.

        Args:
            config: The config with nested operators already rebuilt.
        """
        return cls(**config)

    def __repr__(self) -> str:
        params = ", ".join(f"{k}={v!r}" for k, v in self.get_config().items())
        return f"{type(self).__name__}({params})"

    def __or__(self, other: Operator) -> Sequential:
        """``op1 | op2`` returns ``Sequential([op1, op2])``, flattening on the right.

        ``a | (b | c)`` produces a single three-element `Sequential`.
        """
        # Lazy import — Sequential subclasses Operator.
        from pipekit._base.sequential import Sequential

        if not isinstance(other, Operator):
            return NotImplemented
        if isinstance(other, Sequential):
            return Sequential([self, *other.operators])
        return Sequential([self, other])

    pipekit.ConfigMixin ¶

    Auto-derive get_config() from __init__ parameter names.

    class Sequential(Operator):
    """Apply a list of operators in order, threading the output of each into the next.

    Args:
        operators: A list of `Operator` instances. The empty list is
            allowed but degenerate: ``Sequential([])(x)`` returns ``x``
            unchanged, while ``Sequential([])()`` raises `TypeError`
            (the empty pipeline has no first operator to consult, and
            the carrier has to come from somewhere).

    Raises:
        TypeError: if any element is not an `Operator`, or if any
            non-final element is marked ``_terminal``.

    Example:
        Basic::

            pipe = Sequential([Scale(0.5), Scale(2.0)])
            assert pipe(10.0) == 10.0

        Slice into a sub-pipeline::

            head = pipe[:1]   # Sequential([Scale(0.5)])

        Index a single step::

            first = pipe[0]   # Scale(0.5)
    """

    __config_mixin_auto__ = False  # custom get_config — nested-operator list

    def __init__(self, operators: list[Operator]) -> None:
        for i, op in enumerate(operators):
            require_operator(op, "Sequential", f"operators[{i}]")
        for i, op in enumerate(operators[:-1]):
            if op._terminal:
                raise TypeError(
                    f"Sequential[{i}] is a terminal operator "
                    f"({type(op).__name__}) — terminal operators are only "
                    "valid as the last step of a Sequential."
                )
        self.operators = list(operators)

    @property
    def _is_stateful(self) -> bool:  # type: ignore[override]
        """True if any contained operator is a `StatefulOperator`.

        Overrides the ``_is_stateful: ClassVar[bool] = False`` default
        on `Operator` with a per-instance property — the answer depends
        on what the user composed.
        """
        return any(getattr(op, "_is_stateful", False) for op in self.operators)

    def _apply(self, carrier: Carrier = _MISSING, state: Any = _MISSING) -> Any:
        """Run the pipeline, dispatching between stateless and stateful modes.

        Stateless (the common case): thread ``carrier`` through each
        operator left to right. Stateful — chosen when a ``state`` kwarg
        is supplied or any step is a `StatefulOperator` — delegates to
        `_apply_stateful`, which threads ``(carrier, state)`` pairs. The
        `_MISSING` sentinel distinguishes "argument omitted" from an
        explicit ``None`` so ``pipe(None)`` still means "carrier is None".

        Raises:
            TypeError: Calling an empty pipeline with no input, or
                supplying ``state`` without a carrier.
        """
        if carrier is _MISSING and not self.operators:
            raise TypeError(
                "Sequential([]) cannot be called without an input: "
                "empty pipeline has no operations to perform."
            )
        # Stateful path: any stateful op present *or* state explicitly supplied.
        if state is not _MISSING or self._is_stateful:
            if state is _MISSING:
                raise TypeError(
                    "Sequential contains StatefulOperator(s) but was called "
                    "without a `state` argument. Supply the initial CarryState."
                )
            if carrier is _MISSING:
                raise TypeError(
                    "Sequential was called with `state` but no carrier. "
                    "Stateful pipelines need both: pipe(carrier, state)."
                )
            return self._apply_stateful(carrier, state)
        # Stateless path — original behaviour.
        if carrier is _MISSING:
            out = self.operators[0]()
            remaining = self.operators[1:]
        else:
            out = carrier
            remaining = self.operators
        for op in remaining:
            out = op(out)
        return out

    def _apply_stateful(self, carrier: Carrier, state: Any) -> tuple[Any, Any]:
        """Thread state through stateful ops; pass through stateless ones unchanged.

        Returns ``(carrier, state)`` so the caller can checkpoint or
        feed the state back into the next call.
        """
        out = carrier
        for op in self.operators:
            if getattr(op, "_is_stateful", False):
                out, state = op(out, state)
            else:
                out = op(out)
        return out, state

    def compute_output_signature(self, input_signature: Any) -> Any:
        """Thread the signature through every operator in order.

        A registered carrier is read as its `Signature` first.
        """
        sig = signature_of(input_signature)
        for op in self.operators:
            sig = op.compute_output_signature(sig)
            if sig is None:
                return None
        return sig

    def get_config(self) -> dict[str, Any]:
        return {"operators": [nested_config(op) for op in self.operators]}

    def __or__(self, other: Operator) -> Sequential:

            sig_out = "?" if sig is None else repr(sig)

    class Graph(Operator):
    """A symbolic operator graph with multiple inputs and outputs.

    Construction is implicit — calling operators on `Input` / `Node`
    instances builds the graph; ``Graph(inputs=..., outputs=...)``
    wraps the result. ``_apply(**inputs)`` evaluates in topological
    order.

    Inherits from `Operator` so a `Graph` satisfies the same interface
    as any other operator. ``Operator.__call__`` dispatches keyword
    args straight through to `Graph._apply`; positional args are bound
    to declared `Input`s in declaration order.

    Args:
        inputs: Map of ``input-name → Input`` placeholders. The keys
            are the keyword names accepted by ``__call__``.
        outputs: Map of ``output-name → Node`` (or ``Input``, if the
            output is a direct passthrough). The keys are the keys of
            the returned dict.

    State:
        A graph that contains a stateful node (a `StatefulOperator`, or
        a `Sequential` / `Graph` that contains one) threads a carry state
        the way `Sequential` does: call it as
        ``graph(a=..., b=..., state=s)`` and it returns
        ``(outputs, state)``. The state passes through the stateful nodes
        in topological order (the order `describe` lists); stateless
        nodes ignore it. Inside a stateful `Sequential` the graph receives
        ``(carrier, state)`` positionally, like any stateful step.

    Raises:
        ValueError: if the graph contains a cycle, if an `Input`
            referenced by a node isn't declared in ``inputs``, if a
            required input is missing at call time, or if a stateful
            graph declares an input named ``state`` (the name is the
            carry state's).
    """

    __config_mixin_auto__ = False  # custom get_config — topology, not kwargs

    def __init__(
        self,
        inputs: dict[str, Input],
        outputs: dict[str, Node],
    ) -> None:
        self.inputs = inputs
        self.outputs = outputs
        self._order = self._topological_sort()
        if self._is_stateful and "state" in inputs:
            raise ValueError(
                "A stateful Graph cannot declare an input named 'state': "
                "`state=` is how its carry state is passed. Rename the input."
            )

    @property
    def _is_stateful(self) -> bool:  # type: ignore[override]
        """True if any node's operator is stateful (as for `Sequential`)."""
        return any(
            getattr(node.operator, "_is_stateful", False) for node in self._order
        )

    def _topological_sort(self) -> list[Node]:
        """Return the topological ordering of non-input `Node`s.

        Inputs are sources (supplied by the caller) and are not
        included in the work list. Direct-passthrough outputs (an
        `Input` listed under ``outputs=``) are likewise skipped.
        """
        declared_inputs = set(map(id, self.inputs.values()))
        order: list[Node] = []
        visited: set[int] = set()
        on_stack: set[int] = set()

        def visit(node: Node) -> None:
            node_id = id(node)
            if node_id in visited:
                return
            if node_id in on_stack:
                raise ValueError(
                    "Cycle detected in graph — operator graphs must be DAGs."
                )
            on_stack.add(node_id)
            for parent in node.parents:
                visit(parent)
            on_stack.discard(node_id)
            visited.add(node_id)
            if isinstance(node, Input):
                if node_id not in declared_inputs:
                    raise ValueError(
                        f"Input {node.name!r} is referenced by an output but "
                        "not declared in `inputs=`."
                    )
                return
            order.append(node)

        for output in self.outputs.values():
            visit(output)
        return order

    def _apply(self, *args: Carrier, **inputs: Carrier) -> Any:
        """Evaluate the graph with the supplied inputs (and carry state).

        Accepts inputs either positionally (bound to declared `Input`s
        in declaration order) or by keyword. The positional form lets
        single-input graphs compose into `Sequential` cleanly and lets
        graphs nest inside other graphs — both shapes route values
        through `Operator.__call__`, which only splat positionally.

        Args:
            *args: One value per declared `Input`, in declaration order,
                then, for a stateful call, the state. Mutually exclusive
                with ``**inputs``.
            **inputs: One value per declared `Input`, keyed by name, and
                ``state=`` for a stateful call (unless ``state`` is a
                declared input of a stateless graph).

        Returns:
            ``{output-name: result}`` for each declared output; for a
            stateful call, ``(outputs, state)``.

        Raises:
            TypeError: if positional and keyword inputs are mixed, if the
                number of positional arguments fits neither the inputs
                nor the inputs plus a state, or if a stateful graph is
                called without a state.
        """
        if args and inputs:
            raise TypeError(
                "Graph._apply accepts either positional args (bound to inputs "
                "in declaration order) or keyword inputs, not both."
            )
        state: Any = _MISSING
        if args and len(args) == len(self.inputs) + 1:
            # (carrier..., state): how a stateful Sequential or Graph calls it
            *args_list, state = args
            args = tuple(args_list)
        if "state" in inputs and "state" not in self.inputs:
            state = inputs.pop("state")
        if self._is_stateful and state is _MISSING:
            raise TypeError(
                "Graph contains stateful operator(s) but was called without a "
                "`state` argument. Supply the initial CarryState: "
                "graph(..., state=s)."
            )
        if args:
            if len(args) != len(self.inputs):
                raise TypeError(
                    f"Graph expected {len(self.inputs)} positional argument(s) "
                    f"to bind to inputs {list(self.inputs)}, got {len(args)}."
                )
            inputs = dict(zip(self.inputs, args, strict=True))

        missing = set(self.inputs) - set(inputs)
        if missing:
            raise ValueError(f"Graph missing required input(s): {sorted(missing)}")

        cache: dict[int, Any] = {
            id(self.inputs[name]): inputs[name] for name in self.inputs
        }
        for node in self._order:
            assert node.operator is not None  # guaranteed by _topological_sort
            node_args = tuple(cache[id(p)] for p in node.parents)
            # Route through __call__ so nested operators (Graph, Sequential)
            # get their own dispatch, not just bare _apply.
            if state is not _MISSING and getattr(node.operator, "_is_stateful", False):
                # stateful nodes take the state last and hand it on, in order
                cache[id(node)], state = node.operator(*node_args, state)
            else:
                cache[id(node)] = node.operator(*node_args)

        outputs = {name: cache[id(node)] for name, node in self.outputs.items()}
        if state is _MISSING:
            return outputs
        return outputs, state

    def get_config(self) -> dict[str, Any]:
        """The whole topology: inputs, operators, nodes and outputs.

        Every node is recorded, upstream ones included, so two graphs
        that differ anywhere have different configs (and so different
        `state` records and content hashes). The record::

            {
                "inputs": ["image", "reference"],
                "operators": [<state>, ...],
                "nodes": [{"operator": 0, "parents": [{"input": "image"}]}, ...],
                "outputs": {"ndvi": {"node": 0}, "raw": {"input": "image"}},
            }

        ``operators`` lists each distinct operator once, by identity, in
        first-use order, so an operator shared by several nodes is not
        duplicated. ``nodes`` is in topological order; a parent or an
        output refers either to a declared input by name or to an
        earlier node by index.
        """
        input_names = {id(node): name for name, node in self.inputs.items()}
        node_index = {id(node): i for i, node in enumerate(self._order)}
        operator_index: dict[int, int] = {}
        operators: list[dict[str, Any]] = []
        nodes: list[dict[str, Any]] = []

        def ref(node: Node) -> dict[str, Any]:
            if id(node) in input_names:
                return {"input": input_names[id(node)]}
            return {"node": node_index[id(node)]}

        for node in self._order:
            assert node.operator is not None  # guaranteed by _topological_sort
            op_id = id(node.operator)
            if op_id not in operator_index:
                operator_index[op_id] = len(operators)
                operators.append(node.operator.state)
            parents = [ref(parent) for parent in node.parents]
            nodes.append({"operator": operator_index[op_id], "parents": parents})

        return {
            "inputs": list(self.inputs),
            "operators": operators,
            "nodes": nodes,
            "outputs": {name: ref(node) for name, node in self.outputs.items()},
        }

    @classmethod
    def from_config(cls, config: dict[str, Any]) -> Self:
        """Rebuild a graph from the topology `get_config` records.

        Re-creates each `Input`, then calls each node's operator on its
        parents in the recorded order, which wires the nodes exactly as
        they were; an operator shared by several nodes stays one object.

        Args:
            config: A `get_config` record whose ``operators`` have already
                been rebuilt into `Operator` instances.

        Raises:
            ValueError: if a reference names an undeclared input or a node
                that comes later in the order.
        """
        inputs = {name: Input(name) for name in config["inputs"]}
        operators: list[Operator] = config["operators"]
        built: list[Node] = []

        def lookup(ref: dict[str, Any]) -> Node:
            if "input" in ref:
                if ref["input"] not in inputs:
                    raise ValueError(f"Graph config: undeclared input {ref!r}.")
                return inputs[ref["input"]]
            index = ref["node"]
            if not 0 <= index < len(built):
                raise ValueError(f"Graph config: {ref!r} is not an earlier node.")
            return built[index]

        for spec in config["nodes"]:
            parents = [lookup(ref) for ref in spec["parents"]]
            built.append(operators[spec["operator"]](*parents))
        outputs = {name: lookup(ref) for name, ref in config["outputs"].items()}
        return cls(inputs=inputs, outputs=outputs)

    def __repr__(self) -> str:
        ins = ", ".join(self.inputs)
        outs = ", ".join(self.outputs)
        return f"Graph(inputs=[{ins}], outputs=[{outs}])"

    def output_signatures(self, input_signatures: Any) -> dict[str, Any]:
        """Each output's signature, propagated node by node without data.

        Args:
            input_signatures: ``{input name: Signature}``; a missing name
                means unknown. A single-input graph also takes the bare
                signature.

        Returns:
            ``{output name: Signature | None}``; ``None`` where an
            operator does not track shape, or where a multi-input node's
            inputs disagree (see `summary`).
        """
        signatures = self._node_signatures(input_signatures)
        return {name: signatures[id(node)] for name, node in self.outputs.items()}

    def summary(self, input_signatures: Any = None) -> str:
        """A Keras-style table of the nodes, their input and output signatures.

        Nodes are listed in topological order. Signatures propagate
        through each node's `compute_output_signature`; a node with
        several inputs gets its operator's signature for them only when
        they all agree (an elementwise join), and ``?`` otherwise, since
        `compute_output_signature` takes one input. The outputs follow.

        Args:
            input_signatures: As for `output_signatures`; ``None`` lists
                the structure with every signature unknown.
        """
        signatures = self._node_signatures(input_signatures)
        names = {id(node): name for name, node in self.inputs.items()}

        def label(node: Node) -> str:
            if id(node) in names:
                return names[id(node)]
            return f"[{self._order.index(node)}]"

        def show(signature: Any) -> str:
            if signature is None:
                return "?"
            # a Signature's compact "(y=64, x=64) float32" form
            fmt = getattr(signature, "format", None)
            return fmt() if callable(fmt) else repr(signature)

        rows: list[tuple[str, str, str]] = []
        for i, node in enumerate(self._order):
            parents = ", ".join(label(parent) for parent in node.parents)
            sig_in = ", ".join(show(signatures[id(p)]) for p in node.parents) or "-"
            name = f"[{i}] {type(node.operator).__name__}({parents})"
            rows.append((name, sig_in, show(signatures[id(node)])))
        for out_name, node in self.outputs.items():
            rows.append(
                (f"→ {out_name} = {label(node)}", "", show(signatures[id(node)]))
            )

        w_name = max([len("Node"), *(len(r[0]) for r in rows)])
        w_in = max([len("Input sig"), *(len(r[1]) for r in rows)])
        header = f"{'Node'.ljust(w_name)}  {'Input sig'.ljust(w_in)}  Output sig"
        body = [f"{n.ljust(w_name)}  {i.ljust(w_in)}  {o}" for n, i, o in rows]
        return "\n".join([header, "-" * len(header), *body])

    def _node_signatures(self, input_signatures: Any) -> dict[int, Any]:
        """``id(node) → Signature | None`` for every input and node."""
        if input_signatures is None:
            input_signatures = {}
        elif not isinstance(input_signatures, dict):
            if len(self.inputs) != 1:
                raise TypeError(
                    "This graph has several inputs: pass "
                    "{input name: Signature}, not a single signature."
                )
            input_signatures = {next(iter(self.inputs)): input_signatures}
        unknown = sorted(set(input_signatures) - set(self.inputs))
        if unknown:
            raise ValueError(f"Signatures given for undeclared input(s) {unknown}.")

        signatures: dict[int, Any] = {}
        for name, node in self.inputs.items():
            signatures[id(node)] = signature_of(input_signatures.get(name))
        for node in self._order:
            assert node.operator is not None  # guaranteed by _topological_sort
            parents = [signatures[id(parent)] for parent in node.parents]
            if not parents:
                joined = None
            elif all(parent == parents[0] for parent in parents):
                joined = parents[0]
            else:
                # inputs disagree: compute_output_signature takes one input
                signatures[id(node)] = None
                continue
            signatures[id(node)] = node.operator.compute_output_signature(joined)
        return signatures

    def describe(self) -> str:
        """Return a short topology description.

        Lists inputs, internal nodes (in topological order), and
        outputs. Useful for notebook exploration.
        """
        lines = [
            f"Graph(inputs={list(self.inputs)}, outputs={list(self.outputs)})",
            "  internal nodes (topological order):",
        ]
        for i, node in enumerate(self._order):
            op_name = type(node.operator).__name__ if node.operator else "Input"
            lines.append(f"    [{i}] {op_name}")
        return "\n".join(lines)

    def summary(self, input_signatures: Any = None) -> str:
    """A Keras-style table of the nodes, their input and output signatures.

    Nodes are listed in topological order. Signatures propagate
    through each node's `compute_output_signature`; a node with
    several inputs gets its operator's signature for them only when
    they all agree (an elementwise join), and ``?`` otherwise, since
    `compute_output_signature` takes one input. The outputs follow.

    Args:
        input_signatures: As for `output_signatures`; ``None`` lists
            the structure with every signature unknown.
    """
    signatures = self._node_signatures(input_signatures)
    names = {id(node): name for name, node in self.inputs.items()}

    def label(node: Node) -> str:
        if id(node) in names:
            return names[id(node)]
        return f"[{self._order.index(node)}]"

    def show(signature: Any) -> str:
        if signature is None:
            return "?"
        # a Signature's compact "(y=64, x=64) float32" form
        fmt = getattr(signature, "format", None)
        return fmt() if callable(fmt) else repr(signature)

    rows: list[tuple[str, str, str]] = []
    for i, node in enumerate(self._order):
        parents = ", ".join(label(parent) for parent in node.parents)
        sig_in = ", ".join(show(signatures[id(p)]) for p in node.parents) or "-"
        name = f"[{i}] {type(node.operator).__name__}({parents})"
        rows.append((name, sig_in, show(signatures[id(node)])))
    for out_name, node in self.outputs.items():
        rows.append(
            (f"→ {out_name} = {label(node)}", "", show(signatures[id(node)]))
        )

    w_name = max([len("Node"), *(len(r[0]) for r in rows)])
    w_in = max([len("Input sig"), *(len(r[1]) for r in rows)])
    header = f"{'Node'.ljust(w_name)}  {'Input sig'.ljust(w_in)}  Output sig"
    body = [f"{n.ljust(w_name)}  {i.ljust(w_in)}  {o}" for n, i, o in rows]
    return "\n".join([header, "-" * len(header), *body])

        reject_geotensor(gt, type(self).__name__)
        arr = np.asarray(gt)
        fn = self._resolve_callable()
        if self.batch_size is None:
            return fn(arr)
        return self._batched(fn, arr)

    def _batched(self, fn: Any, arr: np.ndarray) -> np.ndarray:
        """Split ``arr`` along axis 0, call ``fn`` per chunk, concatenate.

        Plain ``np.concatenate`` along axis 0 — works when the model's
        output preserves the batch dimension (the common case).

        Empty inputs (``arr.shape[0] == 0``) are passed straight to the
        model in one call: ``np.concatenate`` cannot accept an empty list
        of chunks, and the model is free to return a meaningful
        zero-length result.

        for start in range(0, n, bs):
            chunks.append(fn(arr[start : start + bs]))
        return np.concatenate(chunks, axis=0)

    class Switch(Operator):
    """Multi-way dispatch on ``key(carrier)``.

    Args:
        key: Callable ``carrier → hashable``. The dispatch key.
        cases: Mapping from key-value to `Operator`. Whichever case
            matches ``key(carrier)`` is applied.
        default: `Operator` for the unmatched case. Defaults to `Identity`.

    Example::

        by_sensor = Switch(
            key=lambda gt: gt.attrs["sensor"],
            cases={
                "sentinel-2": Sentinel2Pipeline(),
                "landsat-8":  Landsat8Pipeline(),
            },
            default=Identity(),
        )
    """

    forbid_in_yaml: ClassVar[bool] = True
    __config_mixin_auto__ = False

    def __init__(
        self,
        key: Callable[..., Hashable],
        cases: dict[Hashable, Operator],
        default: Operator | None = None,
    ) -> None:
        for k, op in cases.items():
            require_operator(op, "Switch", f"cases[{k!r}]")
        if default is not None:
            require_operator(default, "Switch", "default")
        self.key = key
        self.cases = dict(cases)
        self.default = default if default is not None else Identity()

    def _apply(self, x: Any) -> Any:
        k = self.key(x)
        op = self.cases.get(k, self.default)
        return op(x)

    def get_config(self) -> dict[str, Any]:
        return {
            "key": callable_name(self.key),
            "cases": {str(k): nested_config(op) for k, op in self.cases.items()},
            "default": nested_config(self.default),
        }

    def compute_output_signature(self, input_signature: Any) -> Any:
        """The signature every case and the default agree on (else ``None``)."""
        signatures = [
            op.compute_output_signature(input_signature)
            for op in (*self.cases.values(), self.default)
        ]
        return common_signature(*signatures)

    def __repr__(self) -> str:
        cases = ", ".join(f"{k!r}: {op!r}" for k, op in self.cases.items())
        return (
            f"Switch(key={callable_name(self.key)}, cases={{{cases}}}, "
            f"default={self.default!r})"
        )
